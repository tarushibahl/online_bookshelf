# My Library

A personal books and films library that runs in your browser.

## Run it
Double-click `index.html`.

## Your data
Saved in your browser (localStorage) on this laptop.
Use **Export backup** regularly to save a `.json` file, and **Import backup** to restore it.

## Lookups
Book details come from Open Library; film and TV details from the iTunes Search API. Both are free and need no key. An internet connection is needed for lookups only.
